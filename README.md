# Тестовое задание: «Матчи тура» (Expo + React Native + TypeScript)

Решение тестового задания по разработке мобильного/веб-приложения для просмотра матчей тура с поддержкой фильтрации, статусов, таймера обновления и системы избранного.

## 🚀 Запуск проекта

Для запуска проекта необходима Node.js 20+.

```bash
npm install
npm run web      # Запуск и просмотр в браузере
# или
npm start        # Запуск через Expo Go / сканирование QR-кода на телефоне
🛠 Реализованные этапы и исправления
Часть 1. Экран «Матчи тура» (src/screens/MatchesScreen.tsx)
Загрузка данных: Реализована асинхронная загрузка матчей с сервера по адресу MATCHES_URL (из src/config.ts), указывающему на актуальный JSON-файл в репозитории.

Состояния интерфейса:

Отображение индикатора загрузки (ActivityIndicator) в процессе сетевого запроса.

Обработка ошибок с выводом понятного сообщения и интерактивной кнопкой «Повторить».

Пустое состояние («Матчей не найдено») при отсутствии элементов в списке.

Отображение матчей: Карточки содержат наименования команд, города, статус матча на русском языке, текущий счёт (либо плашку «VS» для запланированных игр), а также дату и время начала, адаптированные под часовой пояс устройства.

Фильтрация: Реализованы удобные вкладки Все / Предстоящие / Завершённые. В категорию «Предстоящие» также включены матчи со статусом live (идущие прямо сейчас), так как они ещё не завершены.

Обновление: Добавлены поддержка Pull-to-refresh (RefreshControl), кнопка «Обновить» в шапке интерфейса и интеграция с компонентом UpdatedAgo.

Часть 2. Исправление чужого кода
Звёздочки избранного (useFavorites.ts / FavoriteButton.tsx):

Проблема: Метод indexOf(id) возвращал -1 для отсутствующих элементов, а выражение Boolean(-1) в JavaScript давало true — из-за этого звёздочки ошибочно горели у всех матчей. Кроме того, состояние массива мутировалось напрямую через push/splice, из-за чего React не фиксировал изменения для ререндера.

Решение: Логика проверки заменена на метод includes(id), а обновление стейта переписано с использованием иммутабельного подхода (filter и спред-оператор ...prev).

Таймер «Обновлено N сек назад» (UpdatedAgo.tsx):

Проблема: Использование пустого массива зависимостей [] в useEffect приводило к замыканию начального значения seconds = 0. Таймер инкрементировал нуль и не очищался (clearInterval), а также не сбрасывался при изменении пропа since.

Решение: Добавлена зависимость от since, очистка интервала при размонтировании компонента и точный расчёт прошедших секунд на основе разницы Date.now() - since.getTime().
