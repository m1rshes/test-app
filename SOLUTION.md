# Решение тестового задания «Матчи тура»

## Часть 2. Исправление чужого кода

1. **Проблема со звёздочками в избранном (`useFavorites` и `FavoriteButton`):**
   - **Почему происходило:** Функция `isFavorite` проверяла `Boolean(favorites.indexOf(id))`. Метод `indexOf` возвращает `-1`, если элемент не найден, а `Boolean(-1)` дает `true` — из-за этого звёздочки горели у всех матчей. Кроме того, состояние мутировалось напрямую через `push` и `splice`, из-за чего React не отслеживал изменения массива.
   - **Как исправили:** Заменили проверку на `favorites.includes(id)` и переписали `toggle` с использованием иммутабельного подхода (`...prev` и `filter`).

2. **Проблема с таймером в `UpdatedAgo`:**
   - **Почему происходило:** Хук `useEffect` с пустым массивом зависимостей `[]` захватывал начальное значение `seconds = 0` через замыкание, и каждую секунду инкрементировался нуль (`0 + 1`). Таймер не сбрасывался при обновлении данных и не очищался (`clearInterval`).
   - **Как исправили:** Добавили зависимость от пропа `since`, сброс счётчика при его изменении и расчет точного времени на основе разницы `Date.now() - since.getTime()`.

## Часть 1. Экран «Матчи тура»

- **Обработка статусов и дат:** Английские статусы (`finished`, `live`, `scheduled`, `postponed`) переводятся на русский язык. Для идущих матчей (`live`) выводится текущая минута. Для перенесённых матчей с `startsAt: null` предусмотрена безопасная проверка, исключающая падения приложения.
- **Фильтрация:** 
  - **Все:** выводятся все матчи.
  - **Предстоящие:** отображаются запланированные матчи (`scheduled`) и матчи, которые идут прямо сейчас (`live`), так как они ещё не завершены.
  - **Завершённые:** только матчи со статусом `finished`.
